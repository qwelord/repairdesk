# RepairDesk Studio

Локальное сервисное ателье для ремонта ПК и ноутбуков, согласования смет и подбора компьютерных конфигураций. C# / .NET 8, ASP.NET Core REST API, MySQL / MariaDB, Windows-клиент WPF + WebView2. Без Docker, ORM и миграций.

## Что умеет

- Приём устройств, клиентская база, назначение мастера и контролируемый жизненный цикл заявки.
- CRUD клиентов, комплектующих и услуг через REST API. Используемые записи защищены от удаления.
- Диагностический лист: девять реальных проверок с результатом, наблюдениями, автором и временем.
- Смета с фиксацией цен, записью решения клиента и атомарным переносом согласованных позиций в заказ.
- Учёт деталей, приход и списание, работа с оплатами и возвратами, история действий.
- Студия сборки: совместимость семи компонентов, память, размеры, разъёмы и запас мощности БП.
- 84 комплектующие: по 12 в каждой категории. Вместо выпадающих списков — карточки с поиском, фильтрами бренда, наличия и явных конфликтов, сортировкой цен.
- Подбор полной конфигурации под бюджет, включая работу по сборке; сравнение текущего и предлагаемого ПК.
- Сохранённые проекты, оформление сборки в заказ, поиск по мастерской, печать карточки, CSV-выгрузка и SQL-копия базы.
- Игровые ориентиры для 1080p, 1440p и 4K. Источники и методика доступны прямо у результата; расчёты не маскируются под замеры.

Интерфейс использует локальный шрифт Onest, графитовую навигацию, серебристо-оливковую палитру и фотографии оборудования с Unsplash. Фотографии встроены в комплект и работают без сети; они представляют категории, а не гарантированное изображение конкретной модели. Источники — в `docs/PHOTOS.md`. Здесь нет отдельного экрана с декоративной статистикой: приложение открывается на реальных заявках.

## Запуск без установки .NET

Распакуйте **всю** папку `RepairDesk-Studio-Portable` на Windows 10/11 x64 и запустите `RepairDesk.exe`. Комплект содержит .NET и MariaDB. Администратор Windows, службы, OpenServer и Docker для переносного режима не нужны.

Используется установленный WebView2. Если его нет, приложение открывает тот же интерфейс в браузере по умолчанию; окно RepairDesk должно оставаться открытым. В публикацию также можно включить официальный Fixed Version WebView2.

Демонстрационные логины: `admin`, `reception`, `master`. Пароль: `RepairDesk2026!`. Смените его в настройках после первого входа.

Данные Studio хранятся в `%LOCALAPPDATA%\RepairDesk\studio-v2`, отдельно от первой версии. Перенос папки программы **не переносит пользовательские данные**: для них нужна SQL-копия. Схема Studio — версия 2; старую базу приложение не изменяет и автоматически не конвертирует.

При запуске Studio дополняет каталог недостающими демонстрационными позициями из `database/catalog.sql`, без изменения структуры БД. Совпадающие ID или названия не перезаписываются: цены, остатки и правки сохраняются. Удалённые стартовые позиции могут появиться снова при следующем запуске. Цены и остатки учебные; характеристики и ссылки доступны в карточке. Наличие компонента в каталоге не означает наличие опубликованных FPS-тестов для него.

## Сборка из исходников

Нужны Windows и .NET SDK 8 или новее с поддержкой .NET 8. В Visual Studio — нагрузка «Разработка классических приложений .NET». При первом restore нужен доступ к NuGet либо заранее заполненный кеш пакетов. Node.js не нужен: клиентские HTML/CSS/JS копируются как готовые локальные ресурсы.

```powershell
dotnet restore RepairDesk.sln
dotnet build RepairDesk.sln -c Release
dotnet run --project tests/RepairDesk.Tests -c Release
dotnet run --project tests/RepairDesk.ApiTests -c Release
```

Публикация с извлечённым официальным ZIP MariaDB:

```powershell
.\scripts\publish.ps1 -MariaDbDirectory C:\Tools\mariadb-11.8.9-winx64
```

Для запуска из Visual Studio настройте внешнюю чистую базу по `docs/QUICKSTART.md` или положите переносной сервер в `server` рядом с собранным приложением. Самостоятельная сборка без папки `server` не включает MariaDB автоматически.
