# Запуск RepairDesk на учебном компьютере

## Автономный комплект

1. Скопируйте архив RepairDesk-Portable.zip на Windows 10/11 x64.
2. Распакуйте весь архив в обычную папку, например в Документы. Не запускайте EXE из просмотра ZIP.
3. Откройте RepairDesk.exe. При первом запуске программа подготовит локальную базу и демонстрационные данные.
4. Войдите: логин `admin`, начальный пароль `RepairDesk2026!`.

Интернет, Docker, установленная Visual Studio и .NET не нужны. Библиотеки .NET и Visual C++ для MariaDB входят в комплект. Сервер работает от текущего пользователя без службы Windows и слушает только `127.0.0.1`. Установка от имени администратора не требуется. Политика учебного ПК должна разрешать запуск EXE из выбранной папки.

Первый доступный порт выбирается из 33366–33385. Не открывайте порт в брандмауэре: другие компьютеры для автономного режима не используются.

## Где находятся данные

База и случайно созданные пароли локального сервера хранятся в `%LOCALAPPDATA%\RepairDesk\portable`. Журнал приложения: `%LOCALAPPDATA%\RepairDesk\logs`.

Повторный запуск использует существующие данные. Закрытие RepairDesk штатно останавливает его MariaDB. После аварийного завершения следующий запуск подключается к своему сохранившемуся процессу либо запускает сервер снова. Папку данных нельзя удалять, пока сервер работает.

На другом компьютере первый запуск создаст отдельную учебную базу. Чтобы перенести рабочие данные, сохраните SQL-копию через «Настройки» под администратором. Ее импорт выполняется в новую пустую базу через внешний клиент MySQL; не импортируйте поверх существующей схемы. Экспорт содержит клиентов и хеши паролей.

## Роли

`admin` — все операции, каталог, сотрудники, резервная копия. `reception` — клиенты, прием, оплаты, выдача, склад. `master` — только назначенные ему заказы, диагностика, работы и установка деталей; также просмотр каталога и конфигуратор. Начальный пароль для всех трех демонстрационных записей: `RepairDesk2026!`.

## Работа с Open Server вместо переносимого сервера

Для подключения к Open Server используйте обычную сборку из исходников, без папки `server` рядом с EXE. Запустите MySQL 8.0.13+ или MariaDB 10.6+, создайте базу `repairdesk` и импортируйте `database/schema.sql`, `demo.sql`, `benchmarks.sql` в этом порядке. Если БД создается скриптом, импорт начинайте без ручного создания таблиц.

В окне входа выберите «Настроить подключение» и укажите фактические адрес, порт, пользователя и пароль MySQL. Нажмите «Проверить и сохранить». Для приложения предпочтителен отдельный пользователь с SELECT, INSERT, UPDATE, DELETE на `repairdesk.*`; учетная запись с правами создания таблиц нужна только при первоначальном импорте.

## Если запуск не удался

- «RepairDesk уже запущен»: найдите его окно на панели задач. Второй экземпляр намеренно не открывается.
- Ошибка запуска MariaDB: проверьте `%LOCALAPPDATA%\RepairDesk\portable\server.log`, полный состав распакованного архива и разрешение на запуск сторонних EXE.
- Не подключается обычная сборка: убедитесь, что сервер Open Server запущен, порт совпадает и скрипты импортированы.
- «Заказ изменен другим сотрудником»: обновите список и повторите действие с актуальными данными.
- Не выдается техника: проверьте полную оплату и статус «Готов».
- Не добавляется деталь: проверьте остаток и статус заказа. Для изменения готового заказа сначала верните его в ремонт.
