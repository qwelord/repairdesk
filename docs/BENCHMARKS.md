# Источники и ограничения игровых результатов

Каталог работает без сети. Ссылки открываются только по явному нажатию на источник. Строки базы — измерения авторов обзоров, не результаты тестирования RepairDesk и не обещание FPS выбранной сборки. Studio дополнительно строит явно помеченные расчётные ориентиры; они не записываются в таблицу измерений.

Исполнение XFX отличается от Sapphire из каталога.

В Studio добавлены Hogwarts Legacy, Far Cry 5, Far Cry 6, Metro Exodus (оригинал 2019 года) и Tiny Tina’s Wonderlands. Замеры RTX 4060 взяты из того же обзора KFA2, дата 25.07.2023; новые RX 7600 — из обзора XFX от 31.08.2023. Сохранены конкретные пресеты, RT, масштабирование и оговорки по версии.

Для NBA 2K27 проверенные замеры в исходный набор не включены. Для остальных игр также есть пробелы по GPU и разрешениям. Сообщение об отсутствии данных является предусмотренным поведением.

В `test_date` для агрегатов Notebookcheck записана дата сверки 21.10.2026; это не дата индивидуальных прогонов. Для ComputerBase и Technopat указана дата публикации теста. Версия Cyberpunk зафиксирована как 1.6: эти результаты нельзя выдавать за 2.x. GTA V относится к Legacy, God of War — к игре 2018 года, портированной на ПК в 2022.

Оценка по процессору, частоте RAM, DLSS или генерации кадров не синтезируется. Для точной проверки собранного ПК нужен реальный тест на этом устройстве.

## Расчётная модель Studio

1. При наличии точного GPU/игры/разрешения возвращается исходный средний FPS с типом «Замер из источника».
2. Если есть два замера того же GPU и игры с одинаковыми пресетом, RT и масштабированием, применяется степенная интерполяция по ширине 16:9. Между точками показывается диапазон ±15%, вне диапазона — ±30%.
3. Если прямой результат отсутствует, берётся другой GPU с прямым замером нужной игры и разрешения. Между GPU должно быть минимум две общие игры с совпадающими разрешениями, пресетами, RT и масштабированием; требуется одна публикация либо одно издание с одинаковым описанием CPU/памяти стенда. Медиана отношений применяется к исходному FPS. Показывается диапазон ±35% и все использованные источники. Драйверы и даты могут отличаться.
4. Если условий недостаточно, числовой прогноз не публикуется. В частности, один замер RDR2 в 1080p не превращается произвольным коэффициентом в «измеренный» 4K.

Указанные проценты — прозрачные эвристические коридоры, **не статистические доверительные интервалы и не экспериментально доказанная точность**. Центральное значение не гарантируется. Видеокарты ноутбуков не приравниваются к настольным. Рекомендация не заменяет проверку реальной конфигурации.
