# Проверка Studio

Автоматические тесты — исполняемые консольные проекты, возвращающие ненулевой код при первой неудаче. Это не имитация тестовых отчётов.

```powershell
dotnet build RepairDesk.sln -c Release
dotnet run --project tests/RepairDesk.Tests -c Release
dotnet run --project tests/RepairDesk.ApiTests -c Release
```

Без переменных подключения запускаются проверки бизнес-правил и моделей FPS. Полный изолированный прогон:

```powershell
.\scripts\test-integration.ps1 `
  -MariaDbDirectory C:\Tools\mariadb-11.8.9-winx64 `
  -TestDirectory C:\Temp\RepairDesk-QA-NEW `
  -Port 33370
```

`TestDirectory` обязательно новая. Скрипт не удаляет существующие каталоги, не использует рабочую базу и останавливает созданный сервер в `finally`. Порт должен быть свободен. Тестовый профиль содержит случайный локальный пароль; не публикуйте его.

Проверяются:

- Хеши паролей, проверки полей и переходов статусов, совместимость.
- Аутентификация HTTP-cookie, выход, запрет анонимного доступа, чужого Origin и изменения без специального заголовка.
- Создание, чтение и изменение клиента; сохранение SQL-апострофов; защита связанной записи от удаления.
- Версия заявки и отказ устаревшему запросу; диагностика и заметки через HTTP.
- Фиксация сметы без списания, запрет применения до согласования и повторного применения.
- Корректное списание и возврат деталей, переплата, возврат денег, полный ремонтный цикл.
- Одновременные изменения с единственным победителем; отсутствие двойного списания.
- Сохранение сборки и создание заказа из семи деталей с работой; откат при нехватке.
- Роли мастера, ограничения склада и приёма, защита резервной копии.
- Полная SQL-копия и её восстановление в независимую базу.
- Источники FPS, маркировка интерполяции, отказ смешивать разные пресеты и генерировать числа для неизвестной игры.

Дополнительно интерфейс проверяется в браузере: вход, заявки, каталог, подбор, карточки и модальные формы. Переносная сборка проверяется отдельным запуском на этом Windows-ПК. Проверка на конкретном учебном ПК остаётся необходимой: его политики и доступные браузеры могут отличаться.

Последний полный прогон Studio на MariaDB 11.8.9: **55 проверок HTTP/FPS, 54 проверки бизнес-логики/БД и 12 тестов логики выбора, всего 121 успешная проверка**. Каталог проверяется на 84 позиции и 12 в каждой категории, повторный импорт и сохранность пользовательских цен, остатков и заметок. Сборка решения — 0 предупреждений, 0 ошибок. Это подтверждённый результат конкретного прогона, а не обещание «0 возможных ошибок».
